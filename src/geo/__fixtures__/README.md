# Fixtures

- `wmm2025.json` — World Magnetic Model 2025 Gauss coefficients (g, h, secular variation; n_max 12),
  published by NOAA/NCEI and the British Geological Survey. The WMM is in the public domain
  (U.S. Government work). Extracted from the `geomagnetism` npm package's data file for convenience.
- `wmm2025-test-values.csv` — the official WMM2025 test values (date, alt km, lat, lon, X Y Z H F nT,
  inclination, declination, grid variation) for validating a WMM implementation.
