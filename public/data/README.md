# Data

Generated by `node scripts/build-airports.mjs` from [OurAirports](https://ourairports.com/data/)
(public domain). Re-run the script to refresh; do not edit by hand.

- `airports.json` — large & medium airports with runways and radio frequencies
- `navaids.json` — VOR / VOR-DME / VORTAC / DME / NDB / TACAN
- `small/<latCell>_<lonCell>.json` — small airports with a usable runway, sharded by 10°×10° cell
- `index.json` — counts and shard list

Record formats are documented at the top of `scripts/build-airports.mjs`.
